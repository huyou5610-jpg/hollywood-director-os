# Purpose

Editing Core Engine（ECE）。

负责建立 Hollywood Director OS 的电影剪辑核心系统（Cinema Editing Core）。

Hollywood Director OS 认为：

摄影决定：

拍到了什么。

灯光决定：

观众相信什么。

色彩决定：

观众感受到什么。

而剪辑决定：

**观众何时知道什么。**

真正优秀的剪辑。

不是剪掉多余镜头。

而是：

**重新组织时间、空间与情绪。**

Editing Core 的职责。

就是建立整个电影的节奏系统。

# Core Principle

每一次剪辑必须回答：

```text
为什么这里要切？

↓

为什么现在切？

↓

为什么不是更早？

↓

为什么不是更晚？

↓

```

如果剪辑不能推动故事。

禁止切换镜头。
