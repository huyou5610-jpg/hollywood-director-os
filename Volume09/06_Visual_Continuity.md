# Purpose

Visual Continuity Engine（VCE）。

负责建立 Hollywood Director OS 的电影视觉连续性系统（Cinema Visual Continuity System）。

Hollywood Director OS 认为：

电影。

不是一张画面。

而是：

**无数镜头组成的连续体验。**

观众相信电影。

不是因为单个镜头真实。

而是：

所有镜头之间。

保持：

连续。

统一。

可信。

Visual Continuity 的职责。

就是建立：

**镜头 → 空间 → 人物 → 摄影 → 光线 → 时间 → 连续性**

的完整电影视觉连续体系。
