# Module

# Purpose

Color Pipeline Core Engine（CPC）。

负责建立 Hollywood Director OS 的统一电影色彩科学系统（Color Pipeline）。

Hollywood Director OS 认为：

摄影决定观众看到什么。

灯光决定观众相信什么。

而色彩决定：

**观众感受到什么。**

Color Pipeline 并不是后期调色。

而是贯穿：

导演、美术、摄影、灯光、VFX、AI 视频生成全过程的统一色彩语言。

# Core Principle

每一个色彩方案必须回答：

```text
故事属于什么色彩世界？

↓

角色属于什么色彩关系？

↓

空间具有什么色彩秩序？

↓

情绪如何通过颜色表达？

↓

AI 是否能够稳定保持色彩一致？
```

如果颜色只是漂亮。

没有叙事作用。

则 Color Pipeline 失败。
