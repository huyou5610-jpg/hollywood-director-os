# Purpose

Montage System Engine（MSE）。

负责建立 Hollywood Director OS 的电影蒙太奇系统（Cinema Montage System）。

Hollywood Director OS 认为：

真正优秀的蒙太奇。

不是：

镜头排列。

而是：

**镜头之间诞生新的意义。**

电影。

不是记录现实。

而是：

重新组织现实。

创造新的思想。

新的情绪。

新的时间。

新的空间。

Montage System 的职责。

就是建立：

**镜头 → 关系 → 冲突 → 联想 → 情绪 → 新意义**

的完整电影蒙太奇体系。
