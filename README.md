# 海外真人影视导演系统（HDOS）

本项目将剧本、小说、大纲、对白或创意整理为**真人影视导演方案**，并可按需生成适配 Seedance 2.0 的分镜 Prompt。核心工作流是：

> **先故事、后导演；先表演、后镜头；先设计、后 Prompt。**

项目级 Agent Skill 位于 `.agents/skills/hollywood-director-os/`，入口文件为 `SKILL.md`。原有 `Volume00`–`Volume12` 和两份顶层规则文档作为详细知识库保留，不会因创建 Skill 而被移动或覆盖。

## 快速使用

1. 在支持项目级 Agent Skills 的编辑器/AI Agent 中打开本文件所在的项目根目录。
2. 在 Agent 对话中直接描述任务。Skill 根据任务内容自动匹配；无需额外运行脚本或终端命令。
3. 说明输入素材、目标交付物，以及重要约束。若未提供目标英语地区或视频平台，Agent 会在必要时询问，或把默认假设明确标出。

可以这样提出任务：

- “把下面这段剧本拆成场景、Story Beat 和真人导演分镜，保留原剧情。”
- “将这场中文对白本土化为自然的美式英语，保留人物关系、目的和潜台词，并解释语气选择。”
- “为这几个角色建立真人角色 Bible，锁定脸部身份、发型、体型、服装基准和说话方式。”
- “根据这份分镜生成 Seedance 2.0 Prompt，检查动作节拍、角色状态与镜头连续性。”
- “只审核这组镜头的 180° 轴线、走位和反应镜头，不重写剧情。”

## Skill 能力范围

- **剧本分析**：解析故事、角色、冲突、时间线、场景目标、Story Beat、动作和情绪。
- **导演与分镜**：形成导演意图、观众情绪路径、镜头目的、走位、轴线、Coverage、节奏与转场。
- **真人表演与角色一致性**：设计面部、身体、眼神、呼吸、停顿、互动及跨镜头角色资产锁定。
- **英文本土化**：先理解对白意图、说话目的、关系、情绪和潜台词，再改写为目标地区自然可表演的英语；不逐字翻译、不改剧情。
- **视听设计**：按需规划摄影、灯光、色彩、剪辑、对白、环境声、音乐和特效。
- **AI 视频生成**：把验证后的导演数据编译为 Seedance 等平台可执行的 Prompt，并检查平台约束和状态连续性。
- **制作与验证**：检查结构、叙事逻辑、角色/空间/视听连续性、镜头可读性和生成可执行性。

用户可以请求完整流程，也可以只请求其中一个模块；单项工作仍遵守故事完整性、角色完整性和连续性规则。

## 规则优先级

当规则冲突时，按源系统层级处理：

1. `Volume00/01_System_Rules.md`：最高优先级，包括剧情、角色与连续性保护。
2. `Volume00` 其他文件：系统架构、工作流、输入输出、Seedance 约束、固定模板、质量标准和验证系统。
3. 各卷 Engine / Module 规则：具体创作方法和专业字段。
4. 用户指定的输出风格：不能覆盖更高优先级的故事与连续性约束。

重要原则：不擅自增删关键剧情；镜头服务故事与演员；每镜一个主要目的、每个动作 Beat 一个主要动作、摄影机运动有明确动机；Prompt 描述可见、可执行的状态，并继承前镜状态。若用户明确要求改编或重写，应区分原作内容与改编建议。

## 输出建议

完整导演方案遵循：

`Project → Episode → Sequence → Scene → Segment/Beat → Shot → Director Package → Seedance Prompt`

用户要求完整分镜时，默认提供结构化的项目/场景/镜头信息；Prompt 放在导演数据之后。用户要求严格模板时，使用 `Volume00/05_Output_Template.md` 中的固定字段顺序。只做单项工作时，只输出与该任务相关的部分，并说明必要假设或待确认项。
