# Purpose

Camera Validation Engine（CVE）。

负责建立 Hollywood Director OS 的电影摄影验证系统（Cinema Camera Validation System）。

Hollywood Director OS 认为：

优秀的摄影。

不是：

摄影指导觉得满意。

而是：

整个电影系统验证通过。

Camera Validation 的职责。

就是建立：

**摄影 → 镜头 → 构图 → 调度 → 连续性 → AI 稳定性 → 工业标准**

的完整摄影质量验证体系。

任何未经验证的摄影设计。

不得进入：

Prompt Compiler。

Production Pipeline。

最终生成。
