# Purpose

Character Performance Engine（CPE）。

负责建立 Hollywood Director OS 的角色表演系统（Cinema Character Performance System）。

Hollywood Director OS 认为：

电影中的角色。

不是人物设定。

而是：

**持续做出选择的人。**

真正优秀的角色表演。

不是完成导演要求。

而是：

角色依据自己的信念。

自然行动。

Character Performance 的职责。

就是建立：

**角色 → 动机 → 行动 → 反应 → 成长** 的完整电影角色表演体系。
