# Purpose

Music System Engine（MSE）。

负责建立 Hollywood Director OS 的电影配乐系统（Cinema Music System）。

Hollywood Director OS 认为：

真正优秀的电影配乐。

不是：

观众听见音乐。

而是：

**观众感受到情绪。**

音乐。

不是背景。

而是：

电影情绪。

人物内心。

故事主题。

时间节奏。

共同组成的一部分。

Music System 的职责。

就是建立：

**故事 → 情绪 → 节奏 → 配乐 → 主题 → 电影表达**

的完整电影配乐体系。
