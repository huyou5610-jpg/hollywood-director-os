# Purpose

Body Performance Engine（BPE）。

负责建立 Hollywood Director OS 的电影肢体表演系统（Cinema Body Performance System）。

Hollywood Director OS 认为：

真正优秀的电影表演。

不仅存在于脸。

更存在于：

**身体。**

角色站立的方式。

走路的方式。

呼吸的方式。

都会透露：

他的身份。

心理。

经历。

Body Performance 的职责。

就是建立：

**心理 → 身体 → 动作 → 节奏 → 观众感知** 的完整电影肢体表演体系。
