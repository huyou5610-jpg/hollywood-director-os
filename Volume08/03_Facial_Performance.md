# Purpose

Facial Performance Engine（FPE）。

负责建立 Hollywood Director OS 的电影面部表演系统（Cinema Facial Performance System）。

Hollywood Director OS 认为：

真正优秀的电影表演。

最重要的舞台。

不是身体。

而是：

**脸。**

观众阅读角色。

首先阅读：

表情。

其次阅读：

眼神。

最后才阅读：

对白。

Facial Performance 的职责。

就是建立：

**心理 → 微表情 → 面部动作 → 情绪传达 → 观众共鸣** 的完整电影面部表演体系。
