# Purpose

Lighting Validation Engine（LVE）。

负责建立 Hollywood Director OS 的电影灯光验证系统（Cinema Lighting Validation System）。

Hollywood Director OS 认为：

优秀的灯光。

不是：

看起来漂亮。

而是：

**经过完整验证。**

电影工业。

相信标准。

而不是感觉。

Lighting Validation 的职责。

就是建立：

**灯光理论 → 灯光设计 → 色彩 → 实景光源 → 连续性 → AI稳定性 → 工业验证**

的完整灯光质量验证体系。

任何未经验证的灯光设计。

不得进入：

Prompt Compiler。

Production Pipeline。

最终生成。
