# Purpose

Performance Theory Engine（PTE）。

负责建立 Hollywood Director OS 的电影表演理论系统（Cinema Performance Theory System）。

Hollywood Director OS 认为：

真正优秀的电影表演。

不是角色完成动作。

而是：

**角色正在真实地生活。**

观众不会记住：

演员完成了什么动作。

而会记住：

角色经历了什么人生。

Performance Theory 的职责。

就是建立：

**人物 → 心理 → 行动 → 表演 → 观众共鸣** 的完整电影表演理论体系。
