# Purpose

Ambience Design Engine（ADE）。

负责建立 Hollywood Director OS 的电影环境声音系统（Cinema Ambience Design System）。

Hollywood Director OS 认为：

真正优秀的环境声。

不是背景噪音。

而是：

**空间本身在说话。**

当观众听见：

森林。

城市。

雨夜。

医院。

教堂。

他们应该立即理解：

**故事发生在哪里。**

以及：

**人物正处于怎样的心理空间。**

Ambience Design 的职责。

就是建立：

**空间 → 环境 → 情绪 → 环境声** 的完整电影环境声音体系。
