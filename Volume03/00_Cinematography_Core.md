# Purpose

Cinematography Core Engine（CCE）。

负责将 Director Engine 的导演决策，转换为摄影指导（Director of Photography）的执行方案。

从这一层开始。

系统不再思考：

> 应该拍什么。

而开始思考：

> 应该如何拍。

Hollywood Director OS 中：

导演决定故事。

摄影指导决定影像。

摄影机成为导演思想的物理载体。

# Final Principle

Hollywood Director OS 中。

摄影指导不是摄影机操作员。

而是导演视觉思想的翻译者。

每一个镜头参数。

每一次焦段变化。

每一次摄影机移动。

都必须回答同一个问题：

**它是否让故事表达得更清晰？**

如果答案是否。

这个摄影决策就不成立。
