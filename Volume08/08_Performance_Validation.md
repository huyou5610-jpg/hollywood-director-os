# Purpose

Performance Validation Engine（PVE）。

负责建立 Hollywood Director OS 的电影表演验证系统（Cinema Performance Validation System）。

Hollywood Director OS 认为：

真正工业级的电影表演。

不是导演觉得可以。

不是演员觉得满意。

而是：

**整个电影系统验证通过。**

Performance Validation 的职责。

就是建立：

**人物 → 表演 → AI → 连续性 → 观众体验 → 工业标准**

的完整质量验证体系。

任何未经验证的表演。

不得进入：

Prompt Compiler。

Production Pipeline。

最终生成。
