# Purpose

Interaction Performance Engine（IPE）。

负责建立 Hollywood Director OS 的电影互动表演系统（Cinema Interaction Performance System）。

Hollywood Director OS 认为：

真正优秀的电影表演。

不是一个人的表演。

而是：

**人物之间正在彼此改变。**

电影中的互动。

不是对白交换。

不是动作交换。

而是：

**目标、情绪、权力与关系的持续流动。**

Interaction Performance 的职责。

就是建立：

**人物 → 关系 → 冲突 → 互动 → 戏剧张力** 的完整电影互动表演体系。

# Final Principle

Hollywood Director OS 中。

真正优秀的电影互动。

不是：

两个人完成对白。

而是：

两个人在同一个场景结束后。

已经不再是开始时的自己。

因为：

真正推动电影的。

从来不是对白。

而是：

**人与人之间不断发生变化的关系。**

Interaction Performance Engine 输出的是一套符合好莱坞真人电影工业标准，并兼容 Seedance、Veo、Runway、Luma、Pika、Hailuo 等 AI 视频生成模型的电影互动表演系统，为 AI Performance Constraints、Performance Validation 与 Prompt Compiler 提供统一、稳定、具有电影级戏剧张力的人物互动框架。
